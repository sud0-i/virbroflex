# Вибро-триггер

Android-приложение: слушает микрофон и при шуме включает на виброколонке синус 60 Гц (или импульсы, плавающую частоту, свой аудиофайл). Работает в фоне, есть расписание по времени и дням недели.

## Сборка через GitHub

1. Создайте на GitHub новый репозиторий (можно приватный).
2. Загрузите в него **содержимое** этой папки, включая скрытую папку `.github`.
   - Через сайт: *Add file → Upload files*, перетащите все файлы и папки.
   - Или через git:
     ```
     git init && git add . && git commit -m "init"
     git branch -M main
     git remote add origin https://github.com/ВАШ_ЛОГИН/vibro-trigger.git
     git push -u origin main
     ```
3. Откройте вкладку **Actions**. Сборка запустится сама и займёт 3–5 минут.
4. Готовый файл появится в разделе **Releases** справа на главной странице репозитория: `vibro-trigger.apk`. Если репозиторий приватный, заходите на телефоне под своим аккаунтом GitHub.

Каждое изменение в репозитории запускает новую сборку. Новые версии ставятся поверх старой без удаления, настройки сохраняются.

## Установка

1. Скачайте `vibro-trigger.apk` на телефон и откройте его.
2. Разрешите установку из этого источника, если телефон спросит.
3. Откройте приложение, нажмите «Начать слушать», разрешите микрофон и уведомления.
4. Нажмите «Не ограничивать в фоне» и подтвердите. На Samsung это обязательно.

## Настройка

- Подключите виброколонку по Bluetooth или AUX и поднимите громкость мультимедиа.
- «Проверить звук» — 3 секунды тона.
- «Калибровка порога» — 5 секунд тишины, порог ставится чуть выше фона.
- «Фильтр ниже 200 Гц» не даёт микрофону слышать саму колонку. Не выключайте его при тоне 60 Гц.

## Ограничения

- После перезагрузки телефона запустите приложение вручную: Android не даёт фоновым приложениям включать микрофон без участия пользователя.
- В режиме «Файл» микрофон слышит сам файл, поэтому во время воспроизведения новый шум не продлевает звук. Файл играет «Играть после тишины ещё» секунд от момента срабатывания.
